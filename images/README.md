# Fotos

Hier kommen später echte Fotos hin (Touren, Gruppe, Landschaft).

Tipps:
- Dateinamen klein und ohne Leerzeichen/Umlaute, z. B. `reichenau-runde.jpg`
- Fotos vor dem Hochladen verkleinern (ca. 1600 px breit reicht), sonst lädt die Seite langsam
- Nur Fotos verwenden, an denen ihr die Rechte habt – und bei erkennbaren Personen vorher fragen

Einbinden in HTML, z. B. statt einer Illustration:

```html
<img src="images/reichenau-runde.jpg" alt="Gruppe auf der Insel Reichenau">
```
